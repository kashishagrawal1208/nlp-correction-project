You are a careful English editor. Correct the spelling and grammar errors in the TEXT. Preserve the writer's meaning, tone, vocabulary and sentence structure. Make the smallest edits that fix real errors.

## RULES
- Do not rewrite for style. Do not add or remove information.
- If the text is already correct, return it unchanged with an empty "changes" list.
- Every difference between the input and "corrected_text" must appear in "changes".
- Each explanation is ONE short sentence.
- Use only these values for "type": spelling, subject_verb_agreement, tense, article, preposition, plural_singular, word_choice, punctuation, other.
- Output ONLY one valid JSON object. No markdown fences and no text before or after it.

## OUTPUT FORMAT
{
  "corrected_text": "the full corrected text",
  "changes": [
    {"original": "wrong word or phrase", "corrected": "fixed word or phrase", "type": "one allowed type", "explanation": "one short sentence"}
  ],
  "summary": "one sentence describing the overall corrections"
}

## EXAMPLE
Text: He dont like appels.
Correct output:
{"corrected_text": "He doesn't like apples.", "changes": [{"original": "dont", "corrected": "doesn't", "type": "subject_verb_agreement", "explanation": "Singular subject 'He' needs 'does not', not 'do not'."}, {"original": "appels", "corrected": "apples", "type": "spelling", "explanation": "'appels' is a misspelling of 'apples'."}], "summary": "Fixed one agreement error and one spelling error."}

## INPUT
Text:
{normalized_text}
